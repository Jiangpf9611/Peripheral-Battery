# Peripheral Battery V2.3.0 完整需求规格

基准日期：2026-11-10。产品名称：外设电量；程序：PeriBatt.exe；文件说明：Peripheral-Battery·外设电量；程序集及文件版本：2.3.0.0；产品版本：2.3.0；版权：风车车。

本文件是唯一现行需求文档。依据原完整开发需求、UI 与即时快照调整、音频分类及 V2.3.0 资源优化和移除诊断的最终约定整合。用户已要求删除历史版本及历史需求文件，因此不另存旧需求副本。旧版设备历史、离线保留、720 DIP 宽、Acrylic、估算值“约”前缀、充电文字、诊断模式等均已被最终约定替代。

## 1. 目标、范围与平台

面向需要快速查看外设电量的 Windows 用户：启动自动发现与读取，手动刷新，关闭即退出。以真实性、协议安全、响应速度和简洁界面优先。

运行平台为 Windows 10/11 x64，C# / WinForms / .NET Framework 4.8，Windows 系统 API 与 WinRT。交付单文件 EXE，资源嵌入，不依赖厂商软件或 Python。构建用 Python / Pillow、Windows SDK 和 .NET Framework 参考程序集。

不包含托盘、隐藏常驻、后台设备轮询、电量历史、设备历史数据库、手动增删设备、复杂设置、主题、通知、低电量弹窗、网络扫描、遥测、自动更新、灯效/DPI/键位/固件修改。无 WebView、Electron 等大型框架。

## 2. 生命周期与刷新

- 启动先显示窗口，再异步发现当前设备并查询电量，不等待扫描完成才显示界面。
- 每次启动创建新的内存快照，不加载旧设备行或旧电量；不读写 devices.tsv。
- 手动刷新重新发现和查询；查询期间防止重复点击造成并发风暴，整轮完成后统一更新快照与窗口高度。
- 新发现设备自动增加；可靠确认断开的 USB、蓝牙或 XInput 设备自动移除，无天数或次数阈值。
- 电量超时、协议不支持与外设休眠不等于断开。接收器仍存在时按证据保留当前设备行，显示未知，不伪称无线本体在线。
- 不把蓝牙配对记录、过时节点或缓存名称当作实时在线证据。
- 本会话临时旧值仅在明确标注非当前读数时允许，不跨启动保存；优先显示未知状态。
- 关闭按钮、Alt+F4 退出进程，取消查询、释放句柄、停止动画计时器，不留下守护进程。

## 3. 发现、身份及连接

发现范围包括通用 HID、Windows 设备电池属性、经典蓝牙/BLE 已连接设备、USB/蓝牙音频外设、XInput 手柄及已适配 VGN 设备。

同一物理设备多接口按可靠父节点和有效 ContainerId 聚合。同型号不同实体独立保留；不按名称合并。无共同身份时允许分别显示，不虚构跨模式对应。

已确认键盘的蓝牙与 2.4G 精确身份可映射同一运行时 ID，优先真实在线连接，蓝牙在线时优先于可能缓存的接收器结果，切回沿用 ID。映射使用具体身份摘要，换端口或更换设备后不能盲目复用。

BLE 使用 Windows 已连接选择器及远端地址核对；HID 父链到远端蓝牙设备时停止，避免继承主机适配器身份。蓝牙音频按有效同容器关联远端、音频与免提电量节点，不从本机或无效容器继承数值。

连接方式显示 USB、2.4G、蓝牙、Wi-Fi 或未知。USB 接收器不等于外设有线连接；XInput Wired 也不能单独证明实体连接方式。Wi-Fi 仅在存在可靠发现和协议时显示，不进行网络扫描；当前无通用 Wi-Fi 适配。

名称优先可靠具体身份映射、Provider 准确名称、系统友好名、清理后的原始名称。VGN V98Pro V2、Dragonfly 3 Master+ 保持稳定名称；飞智冰原狼2 仅用于已经确认的具体指纹，不能凭通用 VID/PID 或字符串推断代际，其他情况使用中性名称。

## 4. 数据模型与真实性

设备包含稳定 ID、ContainerId、名称、类别、连接方式、状态、电量种类、数据来源、原因、时间/新鲜度及充电标志。

- ExactPercent：有效范围 0–100 的可靠协议百分比，连续条。
- EstimatedPercent：电压曲线等估算值，内部必须保留估算类型；最终界面直接显示百分比，不加“约”，不等同精确测量。
- DiscreteLevel：原生档位和标签，分格条，禁止映射为伪百分比。
- Unavailable：无可用电量，显示“—”或已连接，下方“未能识别”。
- ExternalPowerOnly：外部供电语义，不从电池 level 推断满电。

区分 Online、Disconnected、Sleeping、Reading、Error 及 Current、Unknown、Stale。0% 与未知严格区分。无测量时间的接收器回复不能默认新鲜，旧值不冒充当前值。

充电必须来自可靠协议字段，USB、有线、电压高均不够。最终仅显示闪烁绿色小闪电，取消“充电中”文字及分隔点；未知、离线或放电时不残留充电标记。

颜色：0–19% 红，20–50% 黄，51–99% 绿；可信精确 100% 蓝色。满电呼吸仅适用于 ExactPercent 且 Freshness.Current，估算 100%、原生 Full 档位或缓存未知值均不得触发。动画局限条形/小闪电，不让整行闪烁，避免高频重绘并尊重系统动画偏好。

## 5. 协议与设备支持

### 5.1 已适配通道

VGN V98Pro V2 2.4G：严格匹配 320F:5088、Usage FF1C:0092、Input/Output 64 字节，固定只读请求，过滤非目标帧、拒绝无效回复与越界百分比。蓝牙读取 Windows 电池属性，USB 模式不承诺电量。

Dragonfly 3 Master+：严格匹配 391D:1A05、FF02:0002、Input/Output 17 字节，固定 Compx 只读查询，检查长度、命令、状态和校验和。电压曲线独立线性插值，不依赖厂商缓存或运行进程。3795mV→39% 为既有校准样本，禁止硬编码结果。保留估算类型；充电 99% 上限为已知局限，不保证等同官方历史平滑值。

XInput：仅可用电池类型的真实档位可显示。Wired/未知电池类型下 level 不代表满电。多物理手柄/多槽无法可靠对应时不强行绑定。当前飞智实物模式未读通电量。

Windows 蓝牙与音频电量：依赖驱动提供属性，可能缓存；无属性时中性降级。BLE GATT Battery Service 主动查询、更广品牌专有协议和通用 Wi-Fi 查询未实现。

### 5.2 音频类别

区分耳机、耳麦、音箱、声卡/音频接口、通用音频。优先 Windows Core Audio 活动播放端点 FormFactor，以有效 ContainerId 关联；不凭麦克风、已拔出端点、品牌或 USB/蓝牙连接猜类型。

Headset/Headphones 明确信息优先；通用 USB 适配器扬声器插孔不证明接入音箱，已识别适配器保留声卡图标；LineLevel/SPDIF 为接口；Display/未知保持通用类型。不修改默认音频设备和驱动，不将所有主板/显示器端点新增为外设。3.5mm 模拟设备可能只显示声卡。

### 5.3 安全、并发与失败

单轮 HID 枚举；设备白名单与报告几何双重匹配才允许写入已知只读查询。不发送未知 Feature/Output、厂商配置或固件命令。

异步独立读写句柄，校验完整 WriteFile 长度，有限重试、超时和取消；缓冲区在异步完成或取消收束前保持有效。最多两个并发查询；鼠标约 1.5 秒预算，键盘最多三次 450ms。失败应局部降级，不冻结窗口、不用旧数值代替。

发布构建无诊断参数、报告生成、运行日志收集和诊断文件写入。开发 DEBUG 输出不得编入正常发布调用。不得输出本机设备路径、序列号或地址到公开文档。

## 6. 窗口与交互

- 启动窗口在所在屏幕工作区居中，首次检测调整高度后仍居中；用户拖动后及后续刷新不强制回中。首次电量条直接显示当前读数，不从零回跳。
- 单窗口，默认宽 480 DIP，标题 52 DIP，行高 76 DIP，列表上下各 4 DIP；0/1 台等高，最多完整五行，六台起列表内纵向滚动，标题固定，无水平滚动。减少行数后复位滚动位置，极小屏幕保证窗口可操作。
- 白色背景，系统可用圆角及浅描边，取消 Acrylic、灰底、重阴影和重复系统标题栏，无悬停弹窗。
- 顶部左侧定稿 Logo 26 DIP 与黑色标题，右侧真实自启开关、刷新及关闭；间距按字体实际测量，控件间隔约 4 DIP。刷新箭头旋转一圈，禁用/恢复有清晰反馈。
- 使用系统字体，DIP 坐标只缩放一次，支持高 DPI；名称截断不挤压右侧状态，中文英文基线协调。
- 行上层左侧名称及浅色连接方式，右侧百分比/档位/状态；下层连续条、分格条或中性说明，不能添加调试第三行。
- 类型图标使用统一浅灰圆角底座，线宽和视觉尺寸一致；键盘、鼠标、手柄及全部音频类型均保留。手柄外轮廓、十字键和按键完整对称。
- 空列表显示“暂无设备 / 点击刷新重新检测”，首次扫描有加载状态。
- 保留定稿 Logo 母版、多尺寸原生 ICO、32px 托管窗口 ICO、最大 128px 标题 PNG 与所有设备类型矢量绘制分支，包括暂未使用的图标。允许去重嵌入，禁止重新设计 Logo 或为减体积删图标。

## 7. 自启、隐私与交付

当前用户 Run 启动项保存自启选择，开启后正常显示窗口。判断启动项应核对当前 EXE 路径，不能误改其他软件同名项。Windows 禁用启动项时反馈真实状态；移动 EXE 后需重新设置。不以设备数据库保存自启。

不存储设备历史和电量历史，不联网、不遥测。系统正常运行痕迹不等于应用持久化设备数据。当前清理请求另行删除已停用的旧 devices.tsv；程序正常运行不自动删除用户旧文件。

保留单份当前源码、构建工具、必要依赖声明和正式图标资源。构建输出 dist/PeriBatt.exe，Git 排除二进制、测试夹具、缓存和本机隐私文件；可执行文件通过 GitHub Releases 发布。GPL-3.0 授权，版权声明及许可证随源码分发。

自动验证入口 tools/test.ps1：真实报文、错误命令/状态/校验和、无效电压、精确/估算/档位、阈值、供电/离线、HID 保护；0–6/9 行、9→5→2→0、尺寸、滚动复位及 100/125/150/175% 布局比例。夹具渲染不能代替系统缩放或硬件实测。

既有记录有指定键盘、鼠标成功报文及校准样本；V2.3.0 未重新完成所有硬件场景。Windows 10 独立目标机、物理跨模式回切、多显示器 DPI 和真实精确满电动画仍待实机确认。构建可能出现既有 System.Runtime/WinRT CS1701 统一警告；EXE 未签名。不宣称所有设备兼容或全需求最终验收通过。
